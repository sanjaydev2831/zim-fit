# Zim Fit

Evidence-based **12-week gym trainer guide** — daily sessions, week-by-week difficulty, and safety limits grounded in ACSM, NSCA, and public physical-activity guidelines.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## What’s inside

- **Start screening** — experience level, goal, ACSM/EIM-style symptom checklist
- **Today / Program** — full 12-week map with trainer briefs
- **Workout view** — warm-up, sets × reps, RPE, cues, swaps, cool-down
- **Safety** — red flags, progression limits, source links

## Progression model

| Weeks | Phase | Structure |
|------:|-------|-----------|
| 1–4 | Foundation | Full body 3× / week · RPE 6–7 |
| 5–8 | Build | Upper / Lower 4× · ~3 sets · RPE 7–8 |
| 9–11 | Intensify | Push / Pull / Legs · heavier compounds |
| 12 | Deload | ~40–50% less volume · RPE 5–6 |

Progressive overload: when you hit the top of the rep range with clean form and ~2 reps in reserve, add ~2–5% load (ACSM-style double progression). Do not spike intensity, volume, and frequency at once.
